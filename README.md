# Blinklabs-io Cardano

## How do I install these formulae?

`brew install blinklabs-io/cardano/<formula>`

Or `brew tap blinklabs-io/cardano` and then `brew install <formula>`.

Or, in a [`brew bundle`](https://github.com/Homebrew/homebrew-bundle) `Brewfile`:

```ruby
tap "blinklabs-io/cardano"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
